# Security Policy

## Reporting a vulnerability

Please report security problems privately using GitHub's
[private vulnerability reporting](https://github.com/Karthigamurugadoss/TuneFetch/security/advisories/new)
instead of opening a public issue. Include steps to reproduce and the affected version or commit.

## Scope

TuneFetch is designed to run locally on `127.0.0.1` for a single user. It has no authentication and uses Flask's development server, so it should not be exposed to the public internet.
